# 주방 환기 3D 플래너

오늘의집 3D 인테리어를 벤치마크한 브라우저 도면·설비 편집기. 명세: `../docs/기능명세.md`.

## 실행
npm install
npm run dev      # http://localhost:5173
npm test
npm run build    # dist/
