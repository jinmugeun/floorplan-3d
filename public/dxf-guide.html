입력 도면 안내

평면도 DXF를 가져와 벽·문·창·방을 자동으로 세웁니다. 선이 적고 레이어가 분명할수록 빠르고 정확합니다. 설계 사무소에 도면을 요청할 때 이 페이지를 함께 보내 주세요.

1. 남길 것과 뺄 것

남겨 주세요

  • 벽·기둥 레이어 — 구조체와 마감선(벽 두께가 보이는 평행선), 기둥 윤곽.
  • 창호 블록 — 문·창을 블록 그대로. 블록 이름에 종류와 폭이 들어 있으면 가장 좋습니다(DR-900, WIN-1200, SD900, 문_슬라이딩 포켓 900).
  • 실명과 면적 문자 — 방 안에 실명, 그 바로 아래에 면적(조리실 / (102.30㎡)).
  • 치수 — 벽·기둥 중심선을 재는 치수. 실 면적(벽 중심선 기준)을 맞추는 근거입니다.

빼 주세요(레이어 끄기·지우기)

  • 기구·가구 — 급식기구, 집기, 위생기구.
  • 설비 — 전기, 급배수, 덕트, 트렌치.
  • 해치 — 벽 채움, 바닥 패턴.
  • 입면·단면·상세, 다른 층, 다른 안(한 파일에 평면 한 장).
  • 범례·표·도면틀(표제란).

끈 레이어는 벽 판정에 쓰지 않습니다. 실명 문자는 꺼진 레이어에 있어도 읽습니다.

2. DWG → DXF 저장 설정

항목설정이유
파일 형식AutoCAD 2007 이상 DXF(ASCII)2007 이상은 문자가 UTF-8이라 한글 실명이 깨지지 않습니다. 바이너리 DXF·DWG는 열 수 없습니다.
블록블록 유지(분해 EXPLODE 하지 않기)창호 블록의 이름이 문·창의 종류와 폭입니다. 분해하면 짐작으로 앉힙니다.
단위mm(INSUNITS = 밀리미터)단위가 없으면 도면 크기로 추정합니다.
공간모델 공간만배치(페이퍼) 공간의 뷰포트·도면틀은 읽지 않습니다.
정리PURGE(안 쓰는 블록·레이어 지우기)파일이 작아지고 읽는 시간이 줄어듭니다.

3. 고쳐서 다시 가져오는 고리

가져오기→정규화 DXF 내보내기→CAD에서 고치기→다시 가져오기

자동으로 뽑은 벽이 틀렸으면 앱에서 하나씩 고쳐도 되고, 더보기 → 정규화 DXF 내보내기로 결과를 깨끗한 DXF로 받아 CAD에서 고친 뒤 다시 가져와도 됩니다. 정규화 DXF는 레이어가 몇 개뿐이라 다시 가져올 때 레이어 판정이 틀릴 일이 없습니다.

CAD에서 고칠 때

  • 벽은 면선 두 줄 + 중심선으로 그려 주세요. 두께는 두 면선 사이 거리입니다.
  • 문·창·통로는 OPENING의 블록을 복사·이동해 쓰세요(블록 이름의 첫 숫자가 폭). 통로 블록(PASS-) 자리의 벽 선은 끊어도 되고 그대로 두어도 됩니다.
  • 방 이름은 ROOM-TEXT의 글자를 고치고, 면적 글자는 이름 바로 아래에 두세요.
  • 저장은 AutoCAD 2007 이상 DXF로.

4. 지금 알려진 한계

  • 폭이 0.6 m보다 좁거나 3 m보다 넓은 통로, 벽 끝과의 토막이 150 mm보다 짧은 통로는 벽을 끊지 않고 PASS- 블록만 둡니다(다시 가져오면 통로입니다).
  • 원형 기둥은 기둥으로 읽히지 않습니다.
  • 두께가 바뀌며 중심이 20 mm 안으로 비낀 벽은 한 중심선으로 맞춰집니다. 앱에서 그린 구획선은 다시 가져오지 않습니다.
